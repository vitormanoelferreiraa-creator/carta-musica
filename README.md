# 💌 Carta Música

Uma página web interativa criada para transformar uma mensagem especial em uma experiência digital personalizada.

A **Carta Música** permite criar uma carta virtual combinando textos, imagens e música em uma experiência pensada para momentos especiais, como declarações, aniversários, datas comemorativas ou simplesmente para demonstrar carinho.

## ✨ Funcionalidades

- 💌 Criação de cartas digitais personalizadas
- 🖼️ Possibilidade de adicionar fotos
- 🎵 Música integrada à experiência
- ✍️ Mensagens personalizadas
- 🌐 Acesso diretamente pelo navegador
- 📱 Compatibilidade com dispositivos móveis

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## 🎯 Objetivo do projeto

O objetivo da **Carta Música** é oferecer uma forma simples e criativa de transformar mensagens em experiências digitais especiais.

A proposta é permitir que uma pessoa personalize uma carta virtual e compartilhe momentos, sentimentos e lembranças com alguém especial.
